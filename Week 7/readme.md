DSA Practical - Week 7

1. Cycle Detection

Problem: Detect whether a graph contains a cycle  
Approach: Use DFS traversal and track visited and recursion-stack nodes to identify back edges  
Time Complexity: O(V + E)  
Space Complexity: O(V)

2. Find Number of Stages

Problem: Find the number of stages in a multistage graph  
Approach: Traverse the graph structure and compute stage count based on edge progression across levels  
Time Complexity: O(V + E)  
Space Complexity: O(V)
